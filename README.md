# koeki-opendata

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Open data for public interest corporations in Japan. This project provides CSV datasets and scripts to scrape and process corporate records from the official government portal, [公益法人information](https://www.koeki-info.go.jp/).

## Demo Application

A search interface built with this data:

- [Public Foundation Search](https://code4fukui.github.io/koeki-search/)

## Datasets

- **`koeki-corps-details.csv`**: The complete, raw dataset scraped from the source. It includes all corporation types, as well as defunct and test entries. This file is generated by `fetchDetails.js`.
- **`koeki-zaidan.csv`**: A cleaned and filtered dataset containing only Public Interest Incorporated Foundations (公益財団法人). Data is processed to remove duplicates and convert full-width alphanumeric characters to half-width. This file is generated by `filterDetails.js`.

## How to Generate Data

This project uses a two-step process to create the datasets.

### Requirements

- [Deno](https://deno.land/)

### Steps

1.  **Fetch Raw Data**

    The `fetchDetails.js` script scrapes the official website for corporate details by iterating through a sequence of IDs.

    **Note:** Before running, you must manually edit `fetchDetails.js` to set the `start` and `end` sequence numbers for the range you wish to fetch.

    ```bash
    deno run -A fetchDetails.js
    ```

    This command populates `koeki-corps-details.csv`.

2.  **Filter and Clean Data**

    The `filterDetails.js` script processes the raw data from `koeki-corps-details.csv`. It removes duplicates, filters out test entries, and normalizes characters to generate the final `koeki-zaidan.csv` file.

    ```bash
    deno run -A filterDetails.js
    ```
